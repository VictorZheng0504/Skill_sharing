# 三类汇报的页面骨架

每个大类对应一个 Style 工作区（交给 ppt-master 的模板 root）；大类下的子类共用同一个 Style，只换页面骨架。下面的骨架是**起点**，按用户确认的页数增删：页数少时合并相邻页，页数多时拆分结果页或增加补充材料页。页面角色名与对应 Style 的 `Page Role Vocabulary` 一致。

| 大类 | 子类 | style_id | 模板 root |
|---|---|---|---|
| ① 文献汇报 | 组会 / Journal Club / SCI 论文精读 | `med-journal-club` | `${MED_DIR}/templates/styles/med-journal-club/` |
| ② 临床个案报告 | 分享型 / 讨论型 | `med-clinical-case` | `${MED_DIR}/templates/styles/med-clinical-case/` |
| ③ 通用医学报告 | 临床研究 / 指南解读 / 专题进展与治疗格局 / 教学课件 / 科室工作汇报 | `med-general-report` | `${MED_DIR}/templates/styles/med-general-report/` |

## 推荐类型的判断

先读材料再推荐，在前置问题里写出推荐与一句理由，由用户确认：

| 材料特征 | 推荐 |
|---|---|
| 一篇（或少数几篇）已发表论文，目的是读懂、评价 | ① 文献汇报 |
| 单个患者的病历，诊断已明确，目的是分享经验 | ② 临床个案 · 分享型 |
| 单个患者的病历，诊断或治疗仍有争议，或要求"先讨论后揭晓" | ② 临床个案 · 讨论型 |
| 本团队的研究方案、数据或结果 | ③ 通用 · 临床研究（再确认开题/中期/结题/学会报告） |
| 一部或多部指南、共识，目的是解读推荐及变化 | ③ 通用 · 指南解读 |
| 多篇文献、指南、注册试验或监管资料综合成治疗进展/技术格局 | ③ 通用 · 专题进展与治疗格局 |
| 面向学生、住培或护理的知识讲授 | ③ 通用 · 教学课件 |
| 科室运营、质控、年度工作数据 | ③ 通用 · 科室工作汇报 |

边界情况：多篇论文围绕一个新疗法、疾病进展或技术趋势 → ③ 专题进展与治疗格局，而非 ①；围绕指南的推荐强度和版本变化 → ③ 指南解读；带一个病例的专题讲课 → ③ 教学课件（病例作为"典型病例"页）；病例汇报后附文献复习 → 仍是 ②。材料混合、无法判断时，列出两个候选请用户选。

## 1. 文献汇报（med-journal-club）

| # | 页面角色 | 要点 |
|---|---|---|
| 1 | 文献信息 | 题目（原文）、期刊、年份、第一/通讯作者、注册号或 DOI；汇报人与日期 |
| 2 | 临床问题 | 一个真实临床情境或证据缺口；为什么现在值得读这篇 |
| 3 | PICO 与研究设计 | P / I / C / O 四格；研究类型、中心数、随访时长 |
| 4 | 研究流程 | CONSORT/STROBE 流程图，各环节人数 |
| 5 | 基线特征 | 关键变量精简表 |
| 6–7 | 主要结果 | 主要终点原图 + 一句话结论；效应量 + 95% CI |
| 8 | 次要与亚组结果 | 森林图或要点；标注预设/探索性 |
| 9 | 安全性 | 不良事件对比 |
| 10 | 证据评价 | 优点 / 局限 / 偏倚风险 / 外推性 |
| 11 | 临床启示 | 回到第 2 页的问题；"原文结论"与"我们的判断"分开 |
| 12 | 讨论问题 | 2–3 个组会讨论问题 |
| 附 | 补充材料 | 按需 |

页数 ≤ 8 时：合并 3+4、6+7、9 并入 8、11+12。

## 2. 临床个案报告（med-clinical-case）

### 2A. 分享型

| # | 页面角色 | 要点 |
|---|---|---|
| 1 | 封面 | 病例标题（如"以反复发热为首发表现的……一例"）、汇报人、科室、日期 |
| 2 | 病例摘要 | 一句话：谁、什么问题、为什么值得报告 |
| 3 | 主诉与现病史 | 时间线式要点 |
| 4 | 既往史与体格检查 | 阳性体征与重要阴性体征 |
| 5 | 病程时间轴 | 全程概览，后续页面复用同一时间轴并高亮当前段 |
| 6–7 | 关键检查 | 检验表（值/单位/参考范围/时间）、影像与病理原图 |
| 8 | 动态变化 | 关键指标折线图，标注治疗事件 |
| 9 | 诊断与依据 | 诊断标准逐条对应本例证据 |
| 10 | 治疗与转归 | 方案、疗效、随访 |
| 11 | 文献复习 | 本例 vs 既往报道对比表 |
| 12 | 学习要点 | 1–3 条 |

页数 ≤ 8 时：合并 3+4、6+7，8 并入 10。

### 2B. 讨论型

分为**讨论段**与**揭晓段**，讨论段的标题、要点、讲稿、配图都不得出现最终诊断。

| # | 段 | 页面角色 | 要点 |
|---|---|---|---|
| 1 | — | 封面 | 不含诊断的病例标题（如"发热、皮疹伴多器官受累一例"） |
| 2 | 讨论 | 讨论目的 | 今天要解决的具体问题 |
| 3 | 讨论 | 主诉与现病史 / 既往史与体格检查 | 与当时已知信息一致 |
| 4–5 | 讨论 | 关键检查 | 检验表与影像/病理原图；"未查"与"阴性"区分 |
| 6 | 讨论 | 病例特点 | 关键阳性、重要阴性、未解释的矛盾 |
| 7 | 讨论 | 鉴别诊断 | 对照表：诊断 × 支持 / 不支持 / 待查 |
| 8 | 讨论 | 讨论问题 | 1–3 个 |
| 9 | 揭晓 | 诊断与依据（诊断揭晓） | 最终诊断与确诊依据 |
| 10 | 揭晓 | 思路复盘 | 关键线索、误区、转折点 |
| 11 | 揭晓 | 治疗与转归 | 方案与结局 |
| 12 | 揭晓 | 学习要点 | 1–3 条 |

诊断尚未明确、只需要讨论版本时，删去揭晓段，第 8 页后接"下一步诊疗计划"。

### 两种子类共同的要求

- **CARE 要素核对**：在 brief 中填写"CARE 要素核对"表（格式见 brief-schema.md），逐项标注放在哪一页，或"资料未提供"/"资料冲突"/"不适用"。只是核对清单，不阻塞流程。
- **时间轴**：以入院日为第 1 天，"入院第 N 天"由日期推算，登记为 `derived:` 事实；病历中两处记录不一致（如起病时间）时，不得自行取舍，写入"待用户补充"中的"资料冲突"，并在页面上采用用户确认后的版本。
- **文献**：只引用用户提供的文献，或本次运行中检索到并核实了 PMID/DOI 的文献；每条引用登记为事实。两者都没有时，文献复习页保留为"待补充文献"的占位页，不得凭记忆写引用。
- **单例措辞**：疗效只写"治疗后××由 A 变为 B"，不写"证明有效"；"首例""罕见"需有文献支持，否则不用。
- **患者视角与知情同意**：病历中没有就写"资料未提供"，不得编写患者原话。

## 3. 通用医学报告（med-general-report）

### 3A. 临床研究

先确认阶段：开题、中期、结题或学会报告。

| # | 页面角色 | 开题 | 中期 | 结题/学会 |
|---|---|---|---|---|
| 1 | 封面 | ✓ | ✓ | ✓ |
| 2 | 背景与问题 | ✓ | 简 | ✓ |
| 3 | 研究假设与目标 | ✓ | ✓ | ✓ |
| 4 | 研究设计 | ✓ 详 | ✓ | ✓ |
| 5 | 研究对象（纳排） | ✓ | ✓ | ✓ |
| 6 | 终点与统计方法 | ✓ 含样本量估算 | ✓ | ✓ |
| 7 | 研究流程 | 计划 | ✓ 实际 | ✓ |
| 8 | 研究进度 | 时间表 | ✓ 重点 | — |
| 9 | 基线特征 | — | 可选 | ✓ |
| 10 | 主要结果 | — | 预览（如允许） | ✓ |
| 11 | 次要结果与亚组 | — | — | ✓ |
| 12 | 安全性 | — | ✓ | ✓ |
| 13 | 局限与争议 | 预期风险 | ✓ | ✓ |
| 14 | 结论与小结 | 预期成果 | 下一步计划 | ✓ |

未完成的分析一律写"待完成"，不预填数字。

### 3B. 指南解读

| # | 页面角色 | 要点 |
|---|---|---|
| 1 | 封面 | 主题、指南名称与年份（如有）、汇报人、日期 |
| 2 | 背景与问题 | 一个真实临床问题；为什么现在讲 |
| 3 | 背景与问题 | 指南/文献来源一览：名称、机构、年份、证据分级体系 |
| 4–8 | 指南推荐 | 一页一条或一组相关推荐：推荐要点 + 推荐强度 + 证据等级 |
| 9 | 指南对比 | 新旧版本或不同指南的差异对照表 |
| 10 | 局限与争议 | 证据空白、分歧 |
| 11 | 结论与小结 | 实践要点 3 条左右 |
| 12 | 自测与讨论 | 2–3 个问题 |

推荐强度与证据等级按原文写法照录（如"I, A""强推荐，中等质量证据"），登记为事实。

### 3C. 专题进展与治疗格局

| # | 页面角色 | 要点 |
|---|---|---|
| 1 | 封面 | 主题、检索截止日期、汇报人、日期 |
| 2 | 背景与问题 | 一个临床决策问题；本次更新解决什么 |
| 3 | 研究设计 | 资料范围与证据地图：数据库、指南/监管机构、截止日、证据层级 |
| 4 | 背景与问题 | 现行标准治疗与格局概览，作为后续比较基线 |
| 5–8 | 主要结果 | 按机制、人群或决策问题分页；每页显示证据等级和研究设计 |
| 9 | 主要结果 | 指南、监管批准、给付/可及性节点；按地区和日期区分 |
| 10 | 临床启示 | 序贯或决策框架；只使用有证据支持的选择条件 |
| 11 | 局限与争议 | 头对头证据、生物标志物、长期安全性和代表性缺口 |
| 12 | 结论与小结 | 3 条决策信息：对谁、何时、依据什么；可附 1–2 个讨论问题 |

专题进展的强制要求：

- 在 brief 的"汇报设定"写明检索/证据截止日期与地理范围；不得只写"最新"。
- 优先级依次为：正式指南与监管文件、同行评议系统综述/RCT、观察性与事后分析、注册试验状态、会议摘要/预印本、企业披露；后三类必须在页面上标注证据状态。
- 没有头对头试验时，不得根据跨试验数值给药物排名；间接比较必须明确标注。
- 每个研究设计、获批身份、适应证和证据状态都以 `kind: "claim"` 登记到 `facts.json`。
- 监管、注册试验与企业资料的 `source` 写机构、文档标题或注册号、发布日期与本次核实日期。

### 3D. 教学课件

| # | 页面角色 | 要点 |
|---|---|---|
| 1 | 封面 | 课题、授课对象、授课人、日期 |
| 2 | 学习目标 | 2–4 条可检验的目标 |
| 3 | 背景与问题 | 一个引入的临床情境 |
| 4–8 | 知识点 | 一页一个知识点：定义、机制或操作要点，配示意图 |
| 9 | 典型病例 | 来自用户材料；没有就省略，不编写 |
| 10 | 知识点 | 易错点与鉴别 |
| 11 | 结论与小结 | 回扣学习目标 |
| 12 | 自测与讨论 | 2–3 题，答案写在讲稿里 |

### 3E. 科室工作汇报

| # | 页面角色 | 要点 |
|---|---|---|
| 1 | 封面 | 科室、汇报周期、汇报人 |
| 2 | 结论与小结 | 一页总体结论（先说结论） |
| 3–6 | 关键指标 | 一页一类指标：口径、时间范围、同比/环比 |
| 7–8 | 主要结果 | 亮点工作与成果 |
| 9 | 问题与改进 | 问题 → 原因 → 措施 |
| 10 | 结论与小结 | 下一阶段目标与时间表 |

每个指标写明统计口径与时间范围，登记为事实；用户材料中没有的指标不补。
