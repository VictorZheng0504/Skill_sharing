# med_brief.md 与 facts.json 格式

## med_brief.md

`med_brief.md` 会作为来源文件交给 ppt-master，所以它既是给 ppt-master 的权威规划，也是给用户核对的大纲。用中文书写，结构固定如下。

```markdown
# <汇报标题>

## 汇报设定
| 项目 | 值 |
|---|---|
| 汇报类型 | 文献汇报 / 临床个案报告 / 通用医学报告 |
| 子类 | 如 组会；分享型 / 讨论型；临床研究·结题 / 指南解读 / 专题进展与治疗格局 / 教学课件 / 科室工作汇报 |
| Style 模板 | med-journal-club |
| 视觉主题 | T1 临床蓝（med-theme-clinical-blue）/ … / T0 自由风格 |
| 场合与时长 | 课题组组会，15 分钟 |
| 听众 | 课题组研究生与导师 |
| 页数 | 12 |
| 讲稿 | 开启 |
| 来源材料 | sources/paper.pdf；figures/ |
| 证据截止 | 专题进展必填：2026-10-26；中国+国际 |

## 核心信息
一到两句话：听众听完应该记住什么。

## 逐页规划

### P01 · 文献信息
- **页面角色**：文献信息
- **标题**：<结论式标题；封面类页面用原文题目>
- **要点**：
  - ……
- **证据绑定**：`figures/fig1.png`（原文 Fig. 1，原图嵌入）/ 无
- **数字出处**：F001, F002
- **AI 配图**：无 / 需要：<用途>；提示词：<不含任何文字的画面描述>
- **讲稿**：<这一页要说的话，口语化，60–150 字>

### P02 · ……

## CARE 要素核对（仅临床个案报告）
| 要素 | 状态 | 页码 |
|---|---|---|
| 患者信息（人口学、主诉、相关既往史） | 已覆盖 / 资料未提供 / 资料冲突 / 不适用 | P03 |
| 临床发现（体格检查） | | |
| 时间轴 | | |
| 诊断评估（检查、鉴别、诊断依据） | | |
| 治疗干预（药物、剂量、疗程、调整） | | |
| 随访与结局（含不良反应、依从性） | | |
| 讨论（文献对照、局限性） | | |
| 患者视角 | | |
| 知情同意 | | |

## 待用户补充
- <原文未报告或资料未提供、需要用户确认的信息>
- 资料冲突：<字段>：<来源 A 的写法> vs <来源 B 的写法>（临床个案报告必填，没有写"无"）
```

规则：

- 每页的"标题"写这一页确立的结论；文献信息、封面、讨论问题等功能页除外。
- "证据绑定"写真实存在的文件路径与原文图号；没有就写"无"，不得写"示意图"冒充证据。
- 要显示在页面上的出处（页脚等）只写原文位置，如"原文 Table 2，p. 5"；`paper.md` 之类的转换文件名只用于 brief 内部定位，不能出现在页面上。
- "数字出处"列出本页用到的全部 facts.json 数字与文字主张条目 ID；本页没有需登记的证据写"无"。
- 临床个案讨论型的讨论段页面，不得在任何字段中出现最终诊断。

## facts.json（数字与关键主张证据账本）

登记 brief 中出现的每一个数字，以及会影响临床解读的非数字主张，例如研究设计、获批身份、抗体亚型、给药途径和指南推荐强度。`check_facts.py` 用它核对导出的 PPT。

```json
{
  "facts": [
    {
      "id": "F001",
      "value": "HR 0.70 (95% CI 0.59–0.83)",
      "label": "主要终点：心衰住院或心血管死亡",
      "source": "原文 Fig. 2A；Results 第 2 段",
      "must_show": true
    },
    {
      "id": "F002",
      "value": "4744",
      "label": "随机化人数",
      "source": "原文 Fig. 1"
    },
    {
      "id": "F003",
      "value": "降低 30%",
      "label": "相对风险降低（由 HR 0.70 换算）",
      "source": "derived: 1 - HR(F001)"
    },
    {
      "id": "C001",
      "kind": "claim",
      "value": "回顾性研究",
      "label": "研究设计",
      "source": "Methods 第 1 段",
      "match": ["回顾性研究", "retrospective study"],
      "slides": [4],
      "must_show": true
    }
  ],
  "allow": ["2", "3"]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一，建议 `F001` 起递增 |
| `value` | 是 | 原文写法；可以包含多个数字（如 HR 与置信区间写在一起） |
| `label` | 是 | 这个数字是什么 |
| `source` | 是 | 原文位置（图号、表号、段落、页码）或病历位置（检查名称与日期）；派生数字以 `derived:` 开头并写明算法 |
| `must_show` | 否 | `true` 表示这个数字必须出现在 PPT 中（主要终点、确诊依据等） |
| `kind` | 否 | `number`（默认）或 `claim`。`claim` 用于非数字的关键医学主张 |
| `match` | claim 可选 | PPT 中可接受的原样文字或文字数组；省略时使用 `value` |
| `slides` | claim 可选 | 限定必须在哪些页出现；省略时在全文检索 |
| `allow`（顶层） | 否 | 非事实性的数字白名单，如"三个要点"里的 3、组会期数；不要用它放行事实数字 |

核对范围包括正文、表格、原生图表数据和讲稿。文字主张只做明确短语匹配，不做语义推断；自由改写的同义表述必须加入 `match`。数字按数值比较（`0.70` 与 `0.7` 视为相同），日期按年月比较（`2021.11` 与 `2021 年 11 月` 视为相同）；讲稿中为朗读写成汉字的数字（一点五六、十九点四六、二十七例、百分之三十）会先转成阿拉伯数字再比较，单个汉字的常用词（一周、两组、第一）不算数字。以下内容会被自动忽略：页码（单独成框且不大于总页数的整数）、图表编号（Fig. 2A、Table 3）、章节与页码定位（Methods 2.1、p. 3–4、第 5 页）、"95% CI"这一固定说法。
