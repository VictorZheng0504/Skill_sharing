# Medical General Report — Style Specification

> Method and design defaults only. No project communication contract, brand identity, page structure, or SVG prototypes.

## I. Style Overview

| Property | Value |
|---|---|
| Style Name | 通用医学报告 |
| Best Fit | 临床研究：本团队研究的开题、中期、结题汇报，学术会议口头报告，课题申报与基金答辩。指南解读：指南/共识推荐、版本变化与争议。专题进展与治疗格局：多文献、监管资料和注册试验组成的时间敏感型证据更新。教学课件：本科/住培/护理教学、科室小讲课。科室工作汇报：年度/季度工作总结、质控与运营数据汇报 |
| Reusable Intent | 让听众在有限时间内判断：问题是否值得、依据是否可靠、结论是否被证据或数据支撑；教学类还要让听众能复述关键知识点 |
| Sources | med-ppt 自建 Style，2026-10-25；由临床研究汇报 Style 扩展；依据 CONSORT、STROBE 等报告规范、指南解读与医学教学的通行做法整理，非单一外部文档 |

## II. Communication Method

- **Preferred Mode**: custom
- **Mode References**: instructional, pyramid
- **Mode Behavior**: 子类由项目的汇报设定决定，全篇只用一种。pyramid 负责每个结论都回指到证据或数据；instructional 负责让方法、推荐或知识点足够清楚、可复现。**临床研究**按"问题 → 设计 → 结果 → 解释"展开，中期以进度与质控为重点，结题以主要终点为重点。**指南解读**按"临床问题 → 推荐 → 证据等级 → 争议与实践要点"展开。**专题进展与治疗格局**按"决策问题 → 证据地图 → 机制/人群分层 → 决策与证据缺口"展开，始终显示证据截止日和证据状态。**教学课件**按"学习目标 → 知识点 → 病例或示例 → 小结与自测"展开。**科室工作汇报**按"总体结论 → 关键指标 → 亮点与问题 → 改进计划"展开。
- **Argument Flow**: 临床研究——背景与证据缺口、假设、设计（类型、注册号、纳排、样本量、随机化、盲法、终点、统计计划）、研究流程、主要终点、次要终点与亚组、安全性、局限与偏倚、结论与下一步。指南解读——临床问题与背景、指南来源、逐条推荐与证据等级、新旧版本或不同指南的差异、争议点、实践要点。专题进展与治疗格局——临床决策问题、来源与截止日、证据层级、现行格局、按机制或人群分层的进展、指南/监管/可及性、序贯决策、证据缺口与结论。教学课件——学习目标、基础知识、核心知识点（一页一个）、典型病例或示例、易错点、小结、自测题。科室工作汇报——一页总体结论、关键指标与同比/环比、亮点、问题与原因、改进措施与时间表。
- **Page Message Discipline**: 每页确立一个设计要素、一个结果、一条推荐、一个知识点或一个指标；页标题写这一页确立的内容，而非"方法""结果""第二部分"等栏目名。结果图与结论句同页。
- **Claim Discipline**: 临床研究的主要终点与探索性分析在措辞和版面上明确区分，效应量带 95% 置信区间，阴性结果如实呈现，观察性设计不下因果结论，未完成的分析标注"待完成"，不预填数字。指南推荐保留原文的推荐强度与证据等级写法，不改写强度；不同指南的分歧并列呈现，不替指南下结论。教学内容的数字与标准注明出处。工作汇报的指标写明统计口径与时间范围。所有数据只能来自用户提供的材料或已核实的来源。

## III. Page Role Vocabulary

| Role | Communication Job | Evidence Obligation | Composition Tendency |
|---|---|---|---|
| 背景与问题 | 说明为什么讲这个主题或做这项研究 | 以文献、指南或数据具体说明问题，标注引用 | 一页一个问题，结论句主导 |
| 学习目标 | 教学：说明听完应掌握什么 | 2–4 条可检验的目标 | 编号列表 |
| 研究假设与目标 | 研究：陈述要检验什么 | 主要假设与次要目标分开写 | 假设句独立突出 |
| 研究设计 | 研究：让评审判断设计能否回答问题 | 研究类型、注册号、分组、随机化、盲法、随访 | 研究设计示意图优先于大段文字 |
| 研究对象 | 研究：交代人群来源与代表性 | 纳入与排除标准、招募时间与中心 | 双栏对照 |
| 终点与统计方法 | 研究：让结果可被评价 | 终点定义、样本量估算、分析集与统计方法 | 结构化列表 |
| 研究流程 | 研究：交代入组、分组与失访 | 各环节人数与失访原因 | CONSORT/STROBE 原生流程图 |
| 基线特征 | 研究：判断组间可比性 | 关键基线变量与组间比较 | 原生三线表 |
| 主要结果 | 呈现主要终点或核心发现 | 效应量 + 95% CI + P 值，注明分析集 | 结果图主导，一句话结论紧邻 |
| 次要结果与亚组 | 研究：检验稳健性与适用人群 | 标注预设/事后；亚组给交互 P 值 | 森林图或对齐的并列小图 |
| 安全性 | 研究：交代风险 | 不良事件、严重不良事件发生率 | 对比表 |
| 研究进度 | 研究中期：交代完成度与质控 | 入组进度、数据完整性、偏差处理 | 进度条或时间轴，计划与实际并列 |
| 指南推荐 | 指南：逐条呈现推荐 | 推荐原文要点、推荐强度、证据等级、指南名称与年份 | 推荐卡片，强度与等级固定位置 |
| 指南对比 | 指南：呈现版本或来源差异 | 各指南名称、年份与对应条目 | 原生对照表 |
| 知识点 | 教学：讲清一个概念、机制或操作 | 定义、要点与出处 | 示意图或结构图配要点 |
| 典型病例 | 教学：用实例巩固知识点 | 病例来自用户材料，不编写 | 病例要点 + 对应知识点 |
| 关键指标 | 工作汇报：呈现核心数据 | 指标定义、口径、时间范围、同比/环比 | 指标卡或原生柱状/折线图 |
| 问题与改进 | 工作汇报：说明问题、原因与措施 | 每个问题对应数据或事件，措施有负责人或时间 | 问题 → 原因 → 措施三栏 |
| 局限与争议 | 说明不能确立什么或尚有争议之处 | 真实的偏倚来源、证据空白或分歧 | 独立一页 |
| 结论与小结 | 收束主题 | 只陈述证据支持的结论；教学小结回扣学习目标 | 与问题页或目标页呼应 |
| 自测与讨论 | 教学或专题：检验理解、引出讨论 | 2–3 个问题，答案可在讲稿中给出 | 留白充足 |
| 补充材料 | 应对提问 | 完整统计输出、补充表、参考文献 | 允许高密度 |

## IV. Evidence & Data Expression

- **Argument Trace**: 结论 → 结果或推荐 → 证据来源，每一环都在页面上可见；中间断开时直接写明。
- **Charts**: 优先使用原生可编辑图表承载本研究或本科室数据；统计软件导出的结果图（如 KM 曲线、森林图）作为证据图片导入，不手工重画。显示不确定性（误差线、置信区间）；生存曲线保留风险人数；对比面板使用一致的坐标刻度；工作汇报的时间序列标明口径变化点。
- **Tables**: 基线表、结局表用原生三线表；指南对比表、推荐汇总表用原生表格；数字精度与单位一致；P 值格式统一（如 P<0.001）。
- **Sources**: 文献标注作者、期刊、年份；指南标注名称、发布机构与年份；本研究数据标注截止日期与分析集；科室数据标注统计口径与时间范围。
- **Native Editability**: 所有承载数字的表格与简单图表均为原生对象，便于会前修正。

## V. Visual System Defaults

- **Preferred Visual Style**: custom
- **Visual Style References**: swiss-minimal, data-journalism
- **Visual Style Behavior**: 专业克制的学术风格。swiss-minimal 负责网格、左对齐与留白；data-journalism 负责让数据图本身成为页面主角，用一句标注指出关键比较。主色负责框架；研究类的试验组用固定识别色、对照组用灰色；警示色只用于主要结论与安全性警示。教学课件可适当放大字号与留白。
- **Composition**: 结果与指标页以一张图或一张表为中心，结论句位置固定；设计页用一张示意图代替大段文字；推荐页的推荐强度与证据等级位置全篇一致。
- **Density**: 方法页可略密但须结构化；结果页只支撑一个结论；教学页一页一个知识点；补充材料承接全部细节。
- **Decoration**: 细线、模块色条、页码与简称页脚；不使用装饰性医疗插画堆砌。
- **Color Behavior**: 分组颜色（试验/对照、本期/上期）全篇固定；颜色只编码分组或状态，不作装饰性强调；灰度打印可区分。选用视觉主题时，试验组取主题的 secondary，对照组取 muted，警示取 alert。
- **Typography Character**: 数字等高；统计符号与单位格式统一；终点、指标与推荐名称在全篇用同一措辞。

## VI. Image & Icon Direction

- **Preferred Image Rendering**: custom
- **Image Rendering References**: flat, vector-illustration
- **Image Rendering Behavior**: 扁平矢量医学示意图，用于研究设计、干预流程、机制或解剖示意。flat 负责干净色块与无透视构图，vector-illustration 负责准确轮廓。背景白色或透明，不含任何文字、数字或伪文字，标签全部用原生文本添加。
- **Image Usage**: 影像、病理、实验图、统计结果图与指南原文图表是证据，只能原图嵌入。AI 生成图片只用于封面、章节页和示意图，不承载数据。
- **Image Treatment**: 证据图保持原始宽高比，除声明裁剪外不修饰，标注来源与编号；患者影像的去标识化由汇报人自行决定。
- **Icon Treatment**: 一套图标家族，只用于标记反复出现的要素（人群、干预、随访、终点、指标类别），映射全篇固定。

## VII. Review Focus

> Apply this section only after the user explicitly activates visual review. It never triggers that stage.

- 研究类：主要终点与探索性分析明确区分；效应量带 95% CI 并注明分析集；流程图各环节人数相加一致；未完成的分析标注"待完成"。
- 指南类：推荐强度与证据等级与原文一致；不同指南的分歧并列呈现。
- 教学类：每页一个知识点；小结回扣学习目标。
- 工作汇报类：每个指标写明口径与时间范围。
- 分组配色全篇一致；结论强度与证据强度相称。
