# 黑白灰阶 — Brand Specification

> Identity-only preset. No SVG page roster — pages are composed freely under these constraints.

## I. Brand Overview

| Property | Value |
|---|---|
| Brand Name | 黑白灰阶（med-ppt 视觉主题） |
| Use Cases | 需要打印的讲义、投影条件差的会场、正式评审材料 |
| Tone | 冷静、严谨、极简 |
| Sources | 配色参考 yixueAIganhuo-PPT（snowmanzhuang，非商业许可）018 号风格的色系，按原生 PPT 的对比度要求重新取值，非原值照搬；2026-10-25 |

## II. Color Scheme

| Role | HEX | Provenance | Purpose |
|---|---|---|---|
| primary | `#111111` | approx | 标题、框架 |
| secondary | `#4A4F50` | approx | 试验组、次级标题 |
| accent | `#7C9593` | approx | 细线、当前节点；少量使用 |
| alert | `#8B2E2E` | approx | 唯一彩色：关键结论、危急值 |
| positive | `#3F5250` | approx | 支持、恢复正常 |
| bg | `#FFFFFF` | approx | 页面底色 |
| surface | `#F2F3F1` | approx | 模块与表格底纹 |
| border | `#B9C0C2` | approx | 分割线、表格线 |
| text | `#1A1A1A` | approx | 正文 |
| muted | `#6F7476` | approx | 注释、出处、对照组 |

- 除 alert 外全部为灰阶；状态区分必须同时依靠符号（↑ ↓ ✓ ✗ ?）和线型，不能只靠颜色。
- 分组图表用实心与空心、实线与虚线区分。
- 这是视觉主题，不是机构标识；颜色只编码角色（框架、分组、状态），不作装饰。
- 状态色同时配符号（↑ ↓ ✓ ✗ ?），灰度打印下仍可区分。

## IV. Logo

- File: none
- 主题不带任何机构 Logo；用户提供医院或学校 Logo 时，按用户要求放置。

## V. Voice & Tone

- Formality: professional-academic
- Person: 我们 / 本研究 / 本例（中文）
- Emoji: avoid
- Abbreviations: spell-out-first-use（医学缩写首次出现写全称）

## VI. Icon Style

- Preference: linear
- 单色线性医学图标，一套家族贯穿全篇。
