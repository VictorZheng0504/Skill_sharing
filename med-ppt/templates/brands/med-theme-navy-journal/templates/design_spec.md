# 深海军蓝期刊 — Brand Specification

> Identity-only preset. No SVG page roster — pages are composed freely under these constraints.

## I. Brand Overview

| Property | Value |
|---|---|
| Brand Name | 深海军蓝期刊（med-ppt 视觉主题） |
| Use Cases | 学术会议口头报告、课题答辩、学位答辩、基金汇报 |
| Tone | 正式、稳重、学术期刊感 |
| Sources | 配色参考 yixueAIganhuo-PPT（snowmanzhuang，非商业许可）009 号风格的色系，按原生 PPT 的对比度要求重新取值，非原值照搬；2026-10-25 |

## II. Color Scheme

| Role | HEX | Provenance | Purpose |
|---|---|---|---|
| primary | `#0B2E5F` | approx | 封面与章节页整页底色、标题 |
| primary-deep | `#071F3F` | approx | 深色页上的叠加色块 |
| secondary | `#2C8C9C` | approx | 试验组、次级强调 |
| accent | `#C7A66A` | approx | 深色页上的细线与编号；浅色页少量使用 |
| alert | `#B83A32` | approx | 关键结论、安全性警示 |
| positive | `#2C8C9C` | approx | 支持、恢复正常 |
| bg | `#FFFFFF` | approx | 内容页底色 |
| surface | `#EAF2FA` | approx | 模块与表格底纹 |
| text | `#0B1F3A` | approx | 正文 |
| muted | `#5D6F86` | approx | 注释、出处、对照组 |

- 封面、目录与章节页用 primary 整页底色配白字，内容页回到白底；同一类页面全篇一致。
- accent 金色在白底上对比度不足，只用于线条、编号底色，不作正文字色。
- 这是视觉主题，不是机构标识；颜色只编码角色（框架、分组、状态），不作装饰。
- 状态色同时配符号（↑ ↓ ✓ ✗ ?），灰度打印下仍可区分。

## III. Typography

| Role | Family | Weight |
|---|---|---|
| title | `Microsoft YaHei, Arial` | bold |
| body | `Microsoft YaHei, Arial` | regular |
| data | `Arial` | regular |


## IV. Logo

- File: none
- 主题不带任何机构 Logo；用户提供医院或学校 Logo 时，按用户要求放置。

## V. Voice & Tone

- Formality: professional-academic
- Person: 我们 / 本研究 / 本例（中文）
- Emoji: avoid
- Abbreviations: spell-out-first-use（医学缩写首次出现写全称）

## VI. Icon Style

- Preference: linear
- 单色线性医学图标，一套家族贯穿全篇。
