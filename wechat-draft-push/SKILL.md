# 公众号排版 + 推送草稿箱

脚本只用 Python 标准库，入口是 `scripts/wechat.py`（下文 `wechat.py` 都指它，用 Skill 目录下的完整路径调用）。
配置文件在用户目录 `~/.wechat-draft-push/.env`（Windows 是 `C:\Users\<用户名>\.wechat-draft-push\.env`），所有 AI 工具共用一份。

## 红线

1. **AppSecret 不进对话。** 不要让用户把 AppID / AppSecret 发给你，不要读、打印、复制 `.env` 的内容。用户在对话里贴了，提醒他：这个密钥已经暴露，建议去开发者平台重置。配置好没有，只看 `setup` 的输出（只显示"已填 / 未填"）。
2. **只建草稿，不发布。** 发表由用户自己在公众号后台或「公众号助手」App 里点。个人主体的订阅号本来就没有发布接口。
3. **白名单由用户自己加。** 你只负责报出 IP、讲清楚去哪里点。不要建议把白名单设成 `0.0.0.0/0` 这类放开所有 IP 的写法。
4. **必须在用户自己的电脑上跑。** 云端沙箱、云电脑的出口 IP 不固定，加了白名单也会失效。豆包等工具有"云电脑 / 本机"两种模式的，要用本机模式。
5. **重推会覆盖后台改动。** 同一篇文章再推会更新同一篇草稿，用户在后台手改过的内容会被覆盖。再推之前先问用户。

## 第一次使用（按顺序，每步确认通过再往下）

1. 检查 Python：`python3 --version`（Windows 用 `python --version`），要 3.8 以上。没有就让用户装：Mac 运行 `xcode-select --install`；Windows 去 python.org 下载，安装时勾选 "Add python.exe to PATH"。
2. `python3 wechat.py setup`：生成配置文件并用文本编辑器打开。告诉用户：
   - AppID 和 AppSecret 在哪里找：电脑浏览器打开 https://developers.weixin.qq.com/console ，管理员微信扫码登录 → 顶部「我的业务与服务」→ 公众号 → 「基础信息」→「开发密钥」。
   - AppSecret 平台不会一直显示：没记下来就只能点「重置」，重置后旧的立刻失效。
   - 自己粘到文件里保存，不要发给你。
   用户说填好了，再跑一次 `setup`，确认两项都显示"已填"。
3. `python3 wechat.py ip`：
   - 输出"通过"：白名单已经好了，跳到第 4 步。
   - 输出"需要加白名单"（退出码 2）：把脚本报出的 IP 和操作步骤原样告诉用户。保存白名单要公众号管理员的微信扫码确认，管理员不是用户本人的话，要提前约好。等用户说加好了再跑一次 `ip`，直到通过。
   - 其他错误：照报错里的中文提示处理（40125 是 AppSecret 不对，40013 是 AppID 不对）。
4. 用 `examples/示例文章.md` 跑一遍 `push --dry-run`，再真推一次，让用户去草稿箱看效果。示例草稿看完让用户自己在后台删掉。

## 日常：把一篇文章推进草稿箱

1. **整理成模板语法。** 默认模板是 b（反思思辨型），语法见 `references/模板B语法.md`。要点：
   - 开头写信息区（`---` 包起来）：`title`（必填，最多 32 字）、`author`（最多 16 字）、`digest`（摘要，最多 120 字）、`cover`（封面图路径）。
   - 章节用 `## 一、标题`；不支持 `###`、代码块、表格，遇到就改写成加粗段或列表。改写只动格式，不改用户的措辞。
   - 图片写 `[图片：images/xx.png|描述]` 或标准的 `![描述](images/xx.png)`，路径相对文章所在文件夹。还没有图就写 `[图片占位：要放什么]`，推完在后台补。
2. `python3 wechat.py preview 文章.md`：在浏览器里打开手机宽度的预览。让用户看过、满意了再推。
3. `python3 wechat.py push 文章.md --dry-run`：检查标题长度、图片、封面，不调接口。
4. `python3 wechat.py push 文章.md`：上传图片和封面，建草稿。看到 `[完成]` 就告诉用户去草稿箱检查并自己发表。
   - 报"不在白名单"（退出码 2）：家里宽带的 IP 隔一段时间会变，换了网络也会变。把新 IP 和步骤告诉用户，加好后重推。
   - 想另建一篇、不覆盖上次的草稿：加 `--new`。

推送记录存在文章旁边的 `.wechat/` 文件夹里（上传过的图片、草稿 ID），不要删，删了下次会重新上传、另建草稿。

## 想换个排版样式

用户看到喜欢的公众号排版，想做一个自己的模板：照 `references/自制模板.md` 做。新模板就是 `scripts/templates/` 下的一个 `.py` 文件，做好后用 `--template 文件名` 调用，或者在配置文件里把 `TEMPLATE=` 改成它。

## 常见报错

- 61004 / 40164：IP 不在白名单，跑 `ip`。
- 40125：AppSecret 不对，或者在后台重置过。让用户自己改配置文件。
- 40013：AppID 不对。
- 40243：AppSecret 被冻结，去「开发密钥」里解冻。
- 45009：今天的接口调用次数用完了。
- 图片太大：Mac 会自动压缩；Windows 要用户先手动压到 1MB 以下。
